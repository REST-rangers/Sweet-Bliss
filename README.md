# Sweet Bliss – Cofetărie Artizanală

## Descrierea proiectului

Sweet Bliss este o pagină web de prezentare pentru o cofetărie artizanală. Scopul site-ului este de a prezenta produsele oferite, precum torturi, macarons și cupcakes.

Site-ul se adresează persoanelor pasionate de deserturi și are un design modern, în nuanțe de roz pastel și crem.

## Tehnologii utilizate

- HTML5 pentru structura paginii.
- CSS3 pentru stilizarea elementelor.
- Flexbox pentru organizarea meniului și a cardurilor cu produse.
- Media Queries pentru adaptarea paginii la ecrane de dimensiuni diferite.

## Utilizarea inteligenței artificiale

Am utilizat ChatGPT pentru generarea primei versiuni a paginii web, pe baza unui prompt în care am descris tema, structura și aspectul dorit.

## Analiza codului generat

Am utilizat elemente HTML5 semantice precum header, nav, main, section, article și footer pentru organizarea conținutului.

Flexbox este folosit pentru aranjarea meniului de navigare și pentru afișarea cardurilor cu produse pe același rând.

Responsive design-ul este realizat prin Media Queries, care modifică aranjarea elementelor pe ecranele mici.

## Personalizarea manuală

În prima versiune, cardurile produselor conțineau doar titluri și descrieri.

Am îmbunătățit pagina prin:

- Adăugarea imaginilor pentru torturi, macarons și cupcakes.
- Introducerea prețurilor produselor.
- Adăugarea unui efect hover, prin care cardurile se măresc și își schimbă culoarea.
- Ajustarea aspectului fotografiilor folosind proprietatea object-fit: cover.

## Concluzie

Prin realizarea proiectului am învățat cum să folosesc inteligența artificială pentru generarea unei pagini web și cum să analizez și să personalizez codul HTML și CSS obținut.
